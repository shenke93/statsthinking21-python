# Statistical Thinking for the 21st Century — Python Companion

## 📖 Overview
While reading *Statistical Thinking for the 21st Century*, I came up with the idea to reproduce its tables, figures, and examples to deepen the understanding.  However, it is noticed that the official Python code depends heavily on R scripts and pre-computed R results, not "pure Python".

This project aims to:
1. Implement all code examples, tables, and figures **fully using Python**.
2. Explore additional experiments and insights beyond the book’s original content.

## ✨ Features
- **Pure Python Implementations**: No reliance on R scripts or outputs.
- **Reproducible Figures & Tables**: All visualizations generated directly from Python.
- **Reading Notes**: Key takeaways and explanations for each chapter.
- **Extra Experiments**: Extended analyses and alternative perspectives.

## 📂 Project Structure

``` project-root/ ├── code/ # Python scripts to generate figures and tables ├── notes/ # Chapter-by-chapter reading notes ├── experiments/ # Additional analyses and visualizations └── data/ # Example datasets used in the book ```
